Data Dictionary

Every input, every field, every file format

Five datasets feed the pipeline. All spatial layers share one projected coordinate system (EPSG:32646) so roads, boundary, facilities, flood raster and travel-survey coordinates line up exactly.

1 Project Structure

Folder layout on disk

Everything is created automatically under a single project root — nothing needs to be uploaded by hand. Every intermediate result is written to disk, so any stage can be re-run independently by reading the files the previous stage produced.

2 File Formats

Formats used across the pipeline

.shp / .dbf / .shx / .prj / .cpg

ESRI Shapefile bundle — vector geometry (roads, boundary, facilities). Field names are capped at 10 characters.

.tif (GeoTIFF)

Single-band Float32 raster — flood inundation depth, 10 × 10 m resolution, nodata = −9999.

.csv

Tabular data — travel survey inputs and every intermediate / final numeric result (IF, AI, BA, TRI).

.png

Rendered maps and chart outputs — one per pipeline stage, plus a combined contact-sheet overview.
