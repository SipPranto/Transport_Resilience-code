How well did the transport network survive the flood — ward by ward?

The Historical Transport Resilience Index (TRI) reconstructs, from observed-style road, flood, facility and travel-survey data, exactly what happened to a city's transport system during a historical flood event: which roads stayed open, which essential services people could still reach, and how travellers actually adapted.

1 What this is

A retrospective resilience audit, not a prediction

Every number on this site describes what already happened during one historical flood event. There is no machine learning, no forecasting, and no what-if simulation anywhere in the pipeline — every score is a transparent, auditable calculation over real (here: synthetically generated for demonstration) spatial and survey data.

✓  Road–flood overlay, network graph analysis, survey aggregation
✓  Transparent, rule-based formulas — every step is auditable
✓  Fully reproducible: one run_pipeline() call, files on disk at every stage
✗  No machine learning or deep learning models
✗  No predictive or forecasting components
✗  No LLMs, RAG, or generative-AI components anywhere
